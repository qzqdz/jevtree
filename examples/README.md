# Examples (demos only)

These scripts demonstrate APIs. They are **not** the official scoring path.

Do **not** add `examples/afa_*` scoring scripts. Acc/F1-vs-budget goes only through:

```bash
meta-jev eval-afa --config configs/...
```

Project docs (Feishu Wiki):
https://hcnzpmamw7fl.feishu.cn/wiki/PeOfwAaTOik9cDkCOlWcschanEf

## Scripts

- `entropy_split_demo.py` — Play Tennis information gain / gain ratio sanity
- `ticket_routing.py` — five-minute ticket routing story: grow→SOP→run→trace (not an eval; no Acc@budget)
- `data/ticket_routing.csv` — tiny synthetic tickets (regenerated by the demo)
- `artifacts/` — demo tree/SOP JSON outputs
