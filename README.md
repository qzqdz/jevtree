# Meta-Jev

**把你的分类和决策需求，沉淀成一套 Jev 能照着执行的"决定 SOP"。**

## 核心概念：决定 SOP

每个分类/决策需求，本质上都是一套 SOP：
1. 看什么数据（特征）
2. 问什么问题（判断点）
3. 怎么组合结果（决策逻辑）

比如"客服工单路由"的 SOP：
```
第1步：提取特征
  → 工单文本、用户历史、紧急程度、涉及金额

第2步：问 Jev 三个问题（并行）
  → Q1: 这是计费问题吗？(noul: 是/否)
  → Q2: 这是技术问题吗？(noul: 是/否)  
  → Q3: 紧急程度是？(score: 1-5)

第3步：组合决策
  → 如果 Q1 概率 > 0.6 → 路由到 billing
  → 如果 Q2 概率 > 0.6 → 路由到 tech
  → 否则按 Q3 分数分流
```

Meta-Jev 帮你把这套 SOP **自动写出来、自动验证、自动跑、自动优化**。

## 工作流程

```
你描述需求："把客服工单分到 billing/tech/refund 三个团队"
        │
        ▼
┌─────────────────────────────────┐
│  Meta-Jev SOP 生成器（LLM）     │
│  1. 拆解决策点                  │
│  2. 设计特征提取                │
│  3. 写 Jev 问题 + 候选项        │
│  4. 画决策 DAG                  │
│  5. 输出 SOP JSON               │
└─────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────┐
│  SOP 验证器                     │
│  → 检查特征是否存在             │
│  → 检查问题格式是否合法         │
│  → 跑 3 个示例确认能出结果      │
└─────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────┐
│  Jev 运行时（每次决策）         │
│  输入工单 → 跑 SOP → 返回路由   │
└─────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────┐
│  SOP 优化器（后台）             │
│  收集 100 条轨迹 → LLM 反思    │
│  → 修改 SOP → A/B 对比         │
└─────────────────────────────────┘
```

## SOP 的三种决策节点

| 节点类型 | 作用 | 例子 |
|---------|------|------|
| **特征节点** | 从原始数据提取信号 | "工单文本里提到'退款'的次数" |
| **Jev 判断节点** | 问 Jev 一个带候选项的问题 | "这是计费问题吗？(choice: billing/tech/refund)" |
| **组合节点** | 把多个判断结果合成最终决策 | "取概率最高的路由" |

Jev 支持三种问题：
- `choice`：从 N 个选项里选一个（分类任务主力）
- `score`：打 2-10 分（分级/优先级）
- `noul`：是非题（命题成立的概率）

## 目录结构

```
Meta-Jev/
├── src/
│   ├── core/
│   │   ├── sop.py          # SOP 数据结构与校验
│   │   ├── generator.py    # LLM 自动生成 SOP
│   │   ├── runtime.py      # SOP 执行引擎
│   │   └── optimizer.py    # 轨迹收集 + SOP 反思优化
│   ├── sdk/
│   │   └── client.py       # 对外 API：decide() / train()
│   └── cli/
│       └── main.py         # 命令行：生成 SOP、测试、发布
├── examples/
│   ├── ticket-routing/     # 客服工单路由示例
│   └── tool-selection/     # Agent 工具选择示例
└── README.md
```
